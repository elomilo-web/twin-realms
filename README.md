# Twin Realms
Third-person open-world action RPG for Godot 4 (.NET / C#).

## Play the beta
**[Download Beta 1.0 for Windows](beta/)**: open the `beta` folder, download the zip, extract it and run `TwinRealms.exe`. No install needed.

## Develop
Start with `docs/SETUP.md`, then read `CLAUDE.md`. Playtest and release steps: `docs/PLAYTEST.md` and `beta/README.md`.
