# Twin Realms asset kit

116 original models, 8 eye textures and a water shader, made for this game in a bright anime-fantasy style
(inspired by the feel of Genshin Impact and Sword Art Online; no designs are copied from either).
Everything here is generated by code in `tools/kit_gen/` and is released CC0, like the rest of the game's assets.

Previews (drawn by a simple software renderer, so the in-game look will differ a little):
`scene.png`, `nature.png`, `village.png`, `castle.png`, `dungeon.png`, `weapons.png`, `armor.png`, `eyes.png`.

## How the models are made
- Units are metres, Y is up. Scenery sits on y = 0 with its centre at x = z = 0, front facing +Z.
- Weapons: the hand holds the grip at the origin and the blade or head points up (+Y). Shields face +Z.
- Head pieces: origin is the centre of the head. Pauldrons: origin is the top of the shoulder. Capes hang down from the origin.
- No textures. Colour is painted per vertex (`COLOR_0`), so each file is tiny (the whole kit is about 4 MB).
- Materials by name: `TR_Matte`, `TR_Matte2S` (two-sided: grass, flags, cloth), `TR_Metal` (blades, trim), `TR_Glow_<hex>` (crystals, flames, runes: emissive).
- Godot turns on "vertex colour as albedo" for these on import, and `Toon.cs` / `Genshin.cs` then style them like everything else.

## Not done yet (needs the PC)
- Nothing is placed in the world yet. `data/env.json` still points at the Quaternius models; swapping in kit models there is the next step, then screenshots.
- `Avatar.cs` does not use the eye textures or armor pieces yet, and `Weapons.cs` does not load the kit weapons.

- To change a model: edit the matching `tools/kit_gen/assets_*.py`, then run `python tools/kit_gen/build.py` from the repo root (needs Python with numpy and Pillow).

## Anime character models (found, not downloaded)
Code-generated people look crude, so characters should come from real anime-style models. Best free option found:

- **VRoid Studio CC0 sample models** on OpenGameArt: https://opengameart.org/content/vroid-studio-cc0-models
  AvatarSample D, E, F, G, a male and a female base body, and hair samples, as glTF/GLB, all CC0.
  Licence details from pixiv: https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use
  Note: only those listed models are CC0. AvatarSample A, B, C and the default bases inside current VRoid Studio have their own conditions, so do not mix them in.
- **VRoid Studio** itself (free, Windows/Mac) makes custom anime characters with hair, eyes and outfits. Models you export can be used in games, including commercially, but they are not CC0, so they would break this repo's "CC0 only" rule unless that rule is relaxed: https://vroid.com/en/studio/guidelines
- The current bodies (Quaternius Universal Base Characters, CC0) also come in "Regular" and "Teen" proportions, which read more anime than the "Superhero" ones in use now: https://quaternius.com/packs/universalbasecharacters.html

Bringing VRoid models in means: download on the PC, import into Godot, retarget the existing animations to the new skeleton, and point `data/avatar.json` at them. That has to be done and checked in the editor.
