# Stat keys

Skill tree nodes (`data/skilltree.json`, generated by `tools/gen_tree.ps1`), races (`data/races.json`), classes (`data/classes.json`) and skill buffs (`data/skills.json`) all add to one table, `Game.TS`, rebuilt by `Game.RecalcTree()`. Only the keys below are read by the game (`TreeDb.Known`); the bot fails if data uses any other key.

| Key | Effect | Read in |
|---|---|---|
| hp, hpP | max health (flat, %) | PlayerStats.MaxHp |
| mp, mpP | max mana | PlayerStats.MaxMp |
| st | max stamina | PlayerStats.MaxSt |
| def | armor (physical defense) | PlayerStats.Defense |
| mr | magic resist (non-physical hits) | Player.TakeHit |
| res_fire, res_frost, res_lightning, res_poison, res_shadow, res_holy | % resistance to that damage type (cap 75%) | Player.TakeHit, player damage over time |
| evade | % chance to dodge a hit (cap 60%) | Player.TakeHit |
| tenacity | % shorter statuses on you (cap 80%) | StatusSet.Add |
| block | % more damage blocked with a shield | Player.TakeHit |
| thorns | % of melee damage reflected | Player.TakeHit |
| regenHp, regenMp | per second | Player |
| leech, mleech | % of damage dealt returned as health / mana | Enemy.TakeHit |
| manaShield, undying | keystone flags | Player.TakeHit |
| allP | % all damage | WpnDmg, SpellPow |
| meleeP, rangedP, spellP | % melee, bow, spell and wand/staff damage | WpnDmg, SpellPow |
| swordP, greatswordP, axeP, maceP, daggerP, spearP | % damage with that melee weapon | WpnDmg |
| physicalP, fireP, frostP, lightningP, poisonP, shadowP, holyP | % damage of that type (any source) | Enemy.Incoming |
| magToDmg, magToBow, strToBow | attribute conversion | WpnDmg |
| crit, critD | crit chance %, crit damage % | CritChance, CritMult |
| aspd | % attack speed | AtkSpeed |
| castSpd | % faster spell casting | Skills.Compute |
| cdr | % shorter cooldowns | Skills.Compute |
| mcost | % mana cost | Skills.Compute |
| skillP | % skill damage | Skills.Compute |
| aoeP | % skill area | Skills.Compute |
| chain | extra Chain Lightning jumps | PlayerSkills |
| multi, pierce, cleave | weapon keystone flags | Player |
| burn | % legacy fire-staff burn | Projectile |
| armorPen, armorPenP, magicPen, magicPenP | flat / % penetration | Enemy.Incoming |
| statusP | % status duration you inflict | Enemy.ApplyStatuses |
| burnChance, poisonChance, bleedChance, chillChance, shockChance, weakenChance, shredChance, ... | % chance on every hit to inflict | Enemy.ApplyStatuses |
| burnP, bleedP, shredP, ... (status id + P) | % status strength | Enemy.ApplyStatuses |
| healP | % healing | heal skills, zones |
| finisherP, finisherStun, finisherUp | combo finisher damage %, extra stun (s), knock-up | Player.ResolveMelee |
| powerP | % power attack damage | Player.ResolveMelee |
| knockP | % knockback | Player.ResolveMelee |
| reach | % melee reach | Player.ResolveMelee |
| rage | more damage the more health you are missing | Enemy.Incoming |
| move | % movement speed | Player |
| xpP | % experience | PlayerStats.GainXp |

Mitigation (League of Legends style): physical damage is multiplied by 100 / (100 + armor), other types by 100 / (100 + magic resist); below zero it becomes 2 - 100 / (100 - R). Penetration first removes a percentage of the resistance, then a flat amount. Then the per-type resistance applies. "true" damage (bleed) ignores all of it.
