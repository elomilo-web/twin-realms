HOW TO WORK THROUGH THIS FILE (instructions for Claude Code)
--------------------------------------------------------------------------------

1. Read .devloop/INDEX.md first if it exists, then this file. Use the info web
   (system cards, files.json) to find code instead of browsing folders.
2. Find the first item marked [ ]. Phases are in dependency order, so don't
   skip ahead unless the item is blocked.
3. You may do 2-4 items from the same phase together if they touch different
   files.
4. For each item:
   a. Before writing new code, check whether the feature partly exists
      already. Extend it rather than duplicating it.
   b. Build, test, and fix errors.
   c. Check every DONE WHEN line. Take screenshots of anything visual.
   d. Change [ ] to [x] and add a note under the item:
        NOTE (date): what changed, main files touched
   e. If blocked, change [ ] to [!] and add:
        BLOCKED: reason
      Then move on to the next item.
5. Make a git commit after each finished item:
     git commit -m "focus F-XX: <title>"
6. Keep the art style consistent: anime fantasy, block-built world. Anything
   placed in the world must match the block style.
7. If something is unclear, make the most reasonable choice, write it under
   the item as "ASSUMPTION: ...", and keep going.

    Problem: Echo and Resonate do not put skills on cooldown. Find out why
    (for example, is the cooldown skipped when a skill is triggered
    indirectly?) and fix the root cause.
    DONE WHEN:
      - Every way of casting a skill (hotbar, Echo, Resonate, spell chain,
        combo) goes through one shared cooldown/resource function.

      - A test or debug log shows the cooldown starting for every cast path.
    NOTE (2026-11-25): Root causes: (1) auto-cast supports (Arcane Loop, Sentinel, Retaliation, Critical Trigger)
      paid only their own short timer and never checked/started the skill cooldown; (2) Echo/Resonance repeats fire
      .3 s apart, so short-cooldown skills (fire 0.7 s) came back while their echoes still fired = free casts.
      Fix: one gate PayCast() (cooldown + mana + stamina + StartCd + log) for every ROOT cast (hotbar, macro, auto);
      rule for parts of a root cast: Echo/Resonance repeats cost nothing but RESTART the cooldown (ready one full
      cooldown after the last repeat); spell-chain sections and weapon-skill impacts are covered by the root cast's
      cooldown; channels (resurrect) start theirs at the end. Every path logs a [CAST] line with --log-casts.
      Test: capture view test_castpaths (DevCapture "castpaths"): hotbar paid+cd, echoes restart cd, recast after the
      last echo blocked (0.47 s left), auto blocked while on cooldown and paid+cd off cooldown, crafted 3-section spell
      paid 4 s cd with sections 2 and 3 logged. Files: PlayerSkills.cs, PlayerSpellcraft.cs, PlayerDowned.cs,
      UiSpellcraft.cs (debug forge), dev/DevCapture.cs, .devloop/viewpoints.json.

[ ] F-10  GEM SYSTEM
    DONE WHEN:
      - SOCKETS: every gear piece rolls 1-4 sockets when it drops or is
